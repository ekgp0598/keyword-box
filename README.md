# Keyword Box

DB와 서버 없이 실행되는 정적 웹앱입니다. `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

로컬 저장 검증까지 안정적으로 하려면 아래처럼 로컬 HTTP 서버로 실행하는 방식을 권장합니다.

```bash
node scripts/serve.js 4173
```

브라우저 주소:

```txt
http://127.0.0.1:4173
```

## 현재 범위

- 게임 선택: 몸으로 말해요, 텔레스트레이션
- 게임 선택: 고요 속의 외침
- 게임 선택: 몸으로 말해요 - 웃긴 버전
- 난이도 선택: 초급, 중급, 상급, 전체, 섞기
- 제시어 개수 선택: 직접 입력, `+3`, `+5`, `+10`, `+50`, 전체
- 섞기 설정: 초급/중급/상급 개수를 각각 지정
- 타이머 또는 스탑워치 선택
- 타이머 퀵 설정: 15초, 30초, 1분, 2분, 3분, 5분
- O/X 채점, 다음 이동 시 자동 Pass
- 이전/다음 제시어 이동
- 제시어 초기화
- 게임 결과 자동 저장
- 마이페이지에서 즐겨찾기와 히스토리 확인
- 히스토리 제목 수정
- 실제 제시어 사전 연결
- 출제 제시어별 결과 저장

## 저장 방식

현재는 브라우저 `localStorage`에 저장합니다.

- 같은 브라우저에서는 창을 닫았다 열어도 즐겨찾기와 히스토리가 유지됩니다.
- 브라우저 캐시/사이트 데이터를 지우면 기록도 지워집니다.
- 다른 기기나 다른 브라우저로는 동기화되지 않습니다.
- `file://`로 직접 여는 것보다 `http://127.0.0.1:4173`으로 여는 편이 저장 원점이 명확합니다.

나중에 로그인, 개인 사전, 공개 사전, 추천/비추천 기능을 붙일 때 Supabase 같은 DB로 옮기면 됩니다.

## 데이터 검증

사전 데이터를 변경한 뒤에는 아래 명령으로 개수, 빈 값, 중복, 긴 제시어를 확인합니다.

```bash
node scripts/validate-data.js
```

Chrome 원격 디버깅 포트를 열어둔 상태에서는 브라우저 스모크 테스트도 실행할 수 있습니다.

```bash
node scripts/browser-smoke-test.js 9233
```

## 추천 단축키

- `O` 또는 `Enter`: 맞힘
- `X` 또는 `Backspace`: 틀림
- `→`: 다음 제시어, 현재 제시어가 미채점이면 자동 Pass
- `←`: 이전 제시어
