# 제시어 게임

## 1. 프로젝트 설명
파티 게임 진행을 돕는 웹 기반 도구입니다. 로그인 없이 바로 접속해 게임을 선택하고, 난이도와 진행 방식을 설정한 뒤 랜덤 제시어로 파티 게임을 즐길 수 있습니다. 게임 진행자가 종이에 제시어를 옮겨 적거나 매번 새 제시어를 찾는 수고를 덜어줍니다.

- **핵심 게임**: 몸으로 말해요, 고요 속의 외침, 텔레스트레이션
- **대상 사용자**: 파티 게임을 즐기는 모든 사람
- **핵심 가치**: 별도 준비 없이 바로 파티 게임 진행 가능

## 2. 페이지 구조
- `/` - 메인 화면 (게임 선택)
- `/game-setup/:gameId` - 게임 설정 화면
- `/game-play/:gameId` - 게임 진행 화면
- `/result` - 결과 화면
- `/mypage` - 마이페이지 화면

## 3. 핵심 기능
- [x] 메인 화면 - 게임 카드 목록, 검색, 즐겨찾기
- [x] 게임 설정 - 난이도 선택, 제시어 개수, 시간 방식 설정
- [x] 게임 진행 - 제시어 표시, 타이머/스탑워치, 채점
- [x] 결과 화면 - 점수, 소요 시간, 재시작
- [x] 마이페이지 - 즐겨찾기, 히스토리 관리
- [x] 키보드 단축키 지원
- [x] 반응형 디자인

## 4. 데이터 모델 설계
현재는 localStorage 기반으로, Supabase 연결 없이 작동합니다.

### localStorage: favorites
즐겨찾기 게임 ID 목록 (string[])

### localStorage: history
게임 히스토리 목록 (HistoryItem[])
```ts
interface HistoryItem {
  id: string;
  title: string;
  gameId: string;
  gameName: string;
  date: string;
  duration: number; // seconds
  correct: number;
  wrong: number;
  pass: number;
}
```

## 6. 개발 단계 계획

### Phase 1: 메인 화면 + 프로젝트 기초
- 목표: 게임 선택이 가능한 메인 화면 구축
- 산출물: 헤더, 게임 카드 목록, 검색 기능, 즐겨찾기, 라우팅 설정, 기본 레이아웃, 폰트/컬러 설정

### Phase 2: 게임 설정 화면
- 목표: 게임 시작 전 설정을 완료할 수 있는 화면
- 산출물: 난이도 선택, 제시어 개수, 타이머/스탑워치 선택, 단축키 안내

### Phase 3: 게임 진행 화면
- 목표: 실제 게임을 진행하는 핵심 화면
- 산출물: 제시어 표시, 타이머/스탑워치, 채점 버튼, 진행 상황 표시

### Phase 4: 결과 화면 + 마이페이지
- 목표: 게임 결과 확인 및 히스토리/즐겨찾기 관리
- 산출물: 결과 화면, 마이페이지, localStorage 연동
- 상태: ✅ 완료

### Phase 5: 제시어 데이터 + 게임별 UI 차별화
- 목표: 실제 제시어 데이터 구축 및 게임별 UI 세부 조정
- 산출물: 제시어 데이터, 게임별 특화 UI, 애니메이션
- 상태: 진행 중
